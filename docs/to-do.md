# UI-UX

Поточна схекма голонвого екрану включає як елементи які вілповідають за прийом иак і за вілправку.

Tому дублюваня полів для генерації хендшейку і ввееня отриманого через месенджер - не раціональне краще мати перемекач-індікатор.
